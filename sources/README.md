В Markdown сохранены внешние ссылки на иллюстрации из публикаций. Скриншоты, отдельно загруженные в чат, в Git не дублируются. Первая статья представлена TXT-файлом и отдельными иллюстрациями из беседы.

Примеры и наблюдения автора служат материалом для разработки инструкций. Упоминания конкретных продуктов и тарифов требуют новой проверки. Права на публикацию статей и дальнейшее распространение должны быть уточнены отдельно.
