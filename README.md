# Runaway-AI

Библиотека практических Agent Skills на русском языке на основе семи статей проекта «Сбежавшая нейросеть». Содержит **оригинальные Markdown/TXT-тексты**, инструкции и сценарии проверки.

Скиллы используют формат Agent Skills: файл SKILL.md с YAML-полями name и description, подробности находятся в папках references.

## Семь скиллов

| № | Скилл | Назначение |
| --- | --- | --- |
| 1 | [editorial-coauthor](skills/editorial-coauthor/SKILL.md) | Авторские тексты, редактура, факт-чек |
| 2 | [agent-delegation](skills/agent-delegation/SKILL.md) | Делегирование: цель, уровень автономности, развилки, контроль |
| 3 | [agent-safety](skills/agent-safety/SKILL.md) | Безопасность: права, угрозы, аудит, копии и инциденты |
| 4 | [skill-evaluator](skills/skill-evaluator/SKILL.md) | Поиск и проверка сторонних скиллов |
| 5 | [ai-learning-system](skills/ai-learning-system/SKILL.md) | Развитие навыков за вечер, за месяц и на годы |
| 6 | [proactive-assistant-operations](skills/proactive-assistant-operations/SKILL.md) | Проактивный ассистент, расписания, сводки и контроль запусков |
| 7 | [ai-adoption-roadmap](skills/ai-adoption-roadmap/SKILL.md) | Маршрут от чата до кодового, локального или проактивного агента |

Скиллы могут работать совместно. Например, ai-adoption-roadmap выбирает среду, agent-delegation определяет контракт, agent-safety ограничивает риск, proactive-assistant-operations задаёт правила повторяющейся работы.

## Архив

Папка [sources/](sources/README.md) содержит семь исходных текстовых файлов без редакторских изменений. В Markdown сохранены ссылки на иллюстрации из оригинальных статей. Скриншоты, отдельно присланные в беседе, пока не дублируются в Git как локальные PNG.

## Использование

1. Выберите скилл по задаче и прочитайте его SKILL.md.
2. Откройте справочные материалы в references при необходимости.
3. Перед действиями в сторонних сервисах проверьте границы полномочий.
4. Сверьте результат с критериями готовности и [тестовыми сценариями](tests/evaluation-cases.md).

Скилл является инструкцией: сам по себе не устанавливает программы, не даёт доступов и не создаёт расписаний.
