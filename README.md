# Runaway-AI

Практическая библиотека Agent Skills на русском языке, подготовленная на основе четырёх статей проекта «Сбежавшая нейросеть».

Содержит **исходные статьи**, **воспроизводимые процедуры** и **тестовые сценарии**. Скиллы рассчитаны на ассистентов, поддерживающих стандарт Agent Skills (файл SKILL.md с YAML-метаданными), и на ручное использование как рабочие инструкции.

## Скиллы

| Скилл | Когда использовать | Основной результат |
| --- | --- | --- |
| [editorial-coauthor](skills/editorial-coauthor/SKILL.md) | Пост, статья, лонгрид, редактура, авторский текст | Доказательная база, структура, управляемый черновик, факт-чек |
| [agent-delegation](skills/agent-delegation/SKILL.md) | Поручить агенту составную задачу | ТЗ с критериями готовности, полномочиями, точками контроля, проверкой |
| [agent-safety](skills/agent-safety/SKILL.md) | Подключить агента, сервис, файлы, браузер; проверить риски | Права, ограничения ущерба, аудит, план восстановления |
| [skill-evaluator](skills/skill-evaluator/SKILL.md) | Оценить, сравнить или подготовить установку чужого скилла | Отчёт о безопасности, полезности, совместимости и доказательствах |

Один запрос может активировать несколько скиллов. Приоритет для действий с побочными эффектами: сначала agent-safety, затем agent-delegation, затем предметный скилл.

## Структура

- [sources/](sources/README.md) — четыре исходных текста в первоначальном формате, с указанием соответствий.
- [skills/](skills/) — процедуры и справочные файлы.
- [docs/methodology.md](docs/methodology.md) — результаты сопоставления статей и правила извлечения скиллов.
- [tests/evaluation-cases.md](tests/evaluation-cases.md) — ручные сценарии проверки.
- [AGENTS.md](AGENTS.md) — общие правила для агентов, работающих с репозиторием.

## Применение

Подключите нужную папку skills/<имя> в совместимом агенте. Агенту достаточно читать SKILL.md выбранного скилла; дополнительные файлы references он открывает по необходимости. Для ручной работы откройте SKILL.md и следуйте процедуре.

Исполнение операций с внешними сервисами зависит от реальных инструментов и выданных пользователем разрешений. Ни один скилл сам по себе не даёт агенту дополнительных прав.

## Отношение к источникам

Статьи сохранены отдельно от скиллов. Сведения об именах моделей, тарифах, доступности функций и конкретных инцидентах отражают позицию материалов на момент написания и **не считаются текущей спецификацией продукта**. Перед рекомендацией установки, оплаты или изменения безопасности проверяйте актуальные официальные документы. Примеры из статей служат объяснением методики и сами по себе не доказывают её эффективность в новой среде.

**Права на тексты:** наличие исходников в репозитории не означает передачи авторских прав или выдачи открытой лицензии. Перед дальнейшим распространением и переиспользованием проверьте права на публикацию материалов.
